# Greypillar policies

The legal and policy texts of Greypillar LLC, with their full history. Every change is a commit you can read and compare.

**State:** opened 14 November 2026. No text is here yet. Each document arrives when Greypillar accepts it, and the website (greypillar.ai/trust) renders it from this repository.

## What will live here

| Group | Documents |
|---|---|
| Policies | Privacy notice · Cookies · AI disclosure · Acceptable use · Retention and deletion |
| Security | Security overview · Vulnerability disclosure |
| Data | Subprocessors (each change published 30 days before use) |
| Agreements | Customer agreement · Pilot agreement · Order form · Data processing agreement · AI addendum |

Agreements are built on the [Common Paper](https://commonpaper.com/standards/) standard terms, free to use under CC BY 4.0. Each agreement names the standard terms and version it uses.

## How to read a change

Each document carries a version and an effective date. Material changes are announced before they take effect. Follow changes through this repository's commits or the feed on greypillar.ai/trust.
